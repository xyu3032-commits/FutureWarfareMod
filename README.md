# 未来战争 Future Warfare Mod

《未来战争》是 [DroneFlames](https://github.com/makkaX2/DroneFlames-PC-Port) 的未来科技题材模组：纯沙盒自由局，双阵营不对称对战——**人类联邦 vs 机械军团**。

Future Warfare is a future-tech mod for DroneFlames: a free sandbox mode with two asymmetric factions — the **Human Federation** vs the **Machine Legion**.

## 内容 / Content

- 86 种未来单位 + 140 座建筑（含 10 座浮空战舰要塞：巡洋舰 / 战列舰 / 航母 / 轨道炮舰 / 无畏旗舰）
- 战舰深化系统：武器改装、经验等级、编队协同、主动技能、子系统受损、火力模式、指定炮击、甲板容量、维护费与弹药补给
- 专属机制：腐蚀、残骸重构、夺控、钻地、拟态、护盾、方向装甲、全息诱饵、中立资源点、轨道采矿
- 指挥点 + 指挥中心解锁、九资源经济、铁路补给与空投、30 项科技与双阵营各 90 条国策
- 开局保护期（可调）、未来灾害与阵营事件、失控机械群、AI 集火旗舰 / 反玩家联盟 / 跨局学习 / 外交性格
- 东亚 + 北美双地图

## 下载 / Download

到 [Releases](https://github.com/xyu3032-commits/FutureWarfareMod/releases) 下载对应语言包（三个包同为 v1.0.0、同一个 mod id，装哪个就是哪个语言，会互相覆盖；跨语言存档不互通）：

| 包 | 语言 | 文件 |
|---|---|---|
| 中文版 | 简体中文 | `future_warfare.dfmod` |
| English | English | `future_warfare_en.dfmod` |
| Русский | Русский | `future_warfare_ru.dfmod` |

机器可读的目录文件见 [`mod_catalog/catalog.json`](mod_catalog/catalog.json)（含每包大小与 SHA-256）。

## 安装 / Install

1. 下载对应语言的 `.dfmod` 文件。
2. 在游戏内模组管理中导入该文件（或把文件放进游戏的模组导入目录后在游戏内启用）。
3. 新开一局，在选营窗选择人类联邦或机械军团即可开战。
